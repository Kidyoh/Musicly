# Musicly

A clean, minimal Flutter music player for Android, iOS and web.

- **Library**: add songs from your device, search them, see recently played
- **Discover**: stream free music from [Audius](https://audius.co) (no API key needed), with search
- **Player**: play/pause, seek, next/previous, shuffle, repeat, queue, background playback with lock-screen controls (mobile)
- **Extras**: favorites, playback speed, sleep timer, light/dark theme

## Run

```
flutter pub get
flutter run            # pick a device
flutter run -d chrome  # web
```
